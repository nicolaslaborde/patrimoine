Voici une proposition de rubriques pour renseigner le poste **“Charges annuelles”** dans une application de patrimoine.

## 1. Logement / Immobilier

### Résidence principale

* Taxe foncière
* Taxe d’habitation, si applicable
* Assurance habitation
* Charges de copropriété
* Entretien courant
* Travaux récurrents
* Contrat chaudière / chauffage
* Eau
* Électricité
* Gaz
* Fioul / bois / pellets
* Internet / téléphone fixe
* Alarme / télésurveillance
* Jardin / piscine / entretien extérieur

### Biens locatifs

* Taxe foncière
* Assurance propriétaire non occupant, PNO
* Charges de copropriété non récupérables
* Frais de syndic
* Frais de gestion locative
* Assurance loyers impayés
* Entretien / réparations
* Diagnostics obligatoires
* Vacance locative estimée
* Frais bancaires liés au prêt
* Intérêts d’emprunt
* Assurance emprunteur

### Résidence secondaire

* Taxe foncière
* Assurance habitation
* Charges de copropriété
* Énergie
* Eau
* Internet
* Gardiennage
* Entretien jardin / piscine
* Déplacements liés au bien

## Champs utiles pour chaque charge

Pour chaque fiche “charge annuelle”, je te conseille de prévoir ces champs :

| Champ                     | Exemple                                 |
| ------------------------- | --------------------------------------- |
| Nom de la charge          | Assurance habitation                    |
| Catégorie                 | Immobilier                              |
| Bien concerné             | Maison principale / appartement locatif |
| Montant                   | 850 €                                   |
| Périodicité               | Mensuelle / trimestrielle / annuelle    |
| Montant annuel calculé    | 850 €                                   |
| Payeur                    | Nicolas / indivision / SCI              |
| Mode de paiement          | Prélèvement / CB / virement             |
| Déductible fiscalement    | Oui / Non / Partiellement               |
| Récupérable sur locataire | Oui / Non / Partiellement               |
| Date d’échéance           | 15 mars                                 |
| Fournisseur               | Allianz                                 |
| Contrat / référence       | N° contrat                              |
| Lien web                  | Espace client                           |
| Commentaire               | À renégocier en 2026                    |
| Justificatif              | PDF / facture / avis d’impôt            |

## Structure simple que je te conseille

Dans ton application, tu pourrais avoir ces grandes familles :

1. **Immobilier**
2. **Véhicules**
3. **Assurances**
4. **Santé**
5. **Vie courante**
6. **Famille**
7. **Impôts**
8. **Crédits**
9. **Banque / placements**
10. **Professionnel / SCI**
11. **Charges exceptionnelles**
12. **Autres charges**

Et pour chaque charge, prévoir un bouton :

**Mensuel / Trimestriel / Annuel**

avec calcul automatique du montant annuel.
